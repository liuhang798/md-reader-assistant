# GitHub 最新代码拉取脚本设计

## 目标

在项目根目录提供 `pull-from-github.bat`，让 Windows 用户双击后安全地从
`https://github.com/liuhang798/md-reader-assistant.git` 获取 `main` 分支最新代码。

## 行为

1. 以脚本所在目录为工作目录，不依赖用户从哪个目录启动脚本。
2. 检查 Git 是否可用，并确认当前目录是 Git 仓库。
3. 将 `origin` 统一配置为项目的 GitHub 地址。
4. 检测 Windows 系统代理；存在代理时仅为本次 Git 命令使用。
5. 检查已跟踪文件、暂存区和未跟踪文件。工作区不干净时立即停止，不创建提交、
   不暂存文件，也不覆盖本地修改。
6. 对 `origin/main` 执行最多三次获取，每次失败后等待五秒。
7. 使用 `git merge --ff-only origin/main` 更新本地分支。若本地与远程分叉，停止并提示，
   不自动 rebase、不创建合并提交、不强制重置。
8. 更新成功后显示当前提交摘要，并在短暂提示后自动关闭窗口；失败时显示原因并延迟关闭。

## 安全边界

- 不执行 `git reset --hard`、`git clean`、强制推送或删除操作。
- 不自动保存、提交或隐藏用户的本地修改。
- 不自动解决历史分叉或冲突。
- 网络重试只影响读取远程仓库，不修改全局 Git 代理配置。

## 验证

- 使用 `cmd.exe /c` 验证 BAT 语法和成功路径。
- 在临时克隆仓库中验证：远程有新提交时可快进、本地脏工作区会被拒绝。
- 检查项目工作区只包含预期文件改动。
