# 文档收藏功能设计

## 目标

在不复制、不移动、不删除用户原文件的前提下，为侧栏增加可持久化的文档收藏功能。用户可以在“最近阅读”和“资源浏览器”中右键收藏文档，并在独立“收藏”视图中打开、编辑、定位或取消收藏。

## 已确认交互

- 侧栏顶部按“最近 / 收藏 / 资源”排列三个视图。
- 最近阅读和资源浏览器的文档卡片右键菜单均提供“收藏文档”；已经收藏时显示“取消收藏”。
- 收藏视图使用相同的文档卡片和右键菜单，右键可以取消收藏、编辑或打开所在文件夹。
- 收藏只保存文件绝对路径，不复制文件；取消收藏只移除记录，不删除文件。
- 文件被移动、删除或磁盘不可用时，收藏记录继续显示为不可用，用户仍可取消收藏。
- 收藏列表和当前侧栏视图跨重启保留。

## 数据与后端

`Preferences` 新增 `favoriteFiles` 与运行时返回的 `favoriteFileStatuses`。旧版偏好文件缺少字段时自动补为空数组。`AddFavorite(path)` 负责规范化路径、大小写不敏感去重并把新收藏放到列表顶部；`RemoveFavorite(path)` 仅移除记录。`GetPreferences()` 返回每条收藏当前是否存在。

新建草稿“另存为”后，如果草稿已收藏，收藏路径随文档迁移到新路径，避免出现失效的重复收藏。

## 前端状态与菜单

现有 `state` 扩展 `favoriteFiles`，继续作为唯一前端状态源。通用偏好路径映射函数同时生成最近阅读和收藏卡片数据。上下文菜单根据来源视图和收藏状态动态显示动作与文案，不引入第二套菜单状态。

最近阅读、收藏和资源浏览器中的已收藏文档，在文件名前显示随主题色变化的实心五角星。标记仅用于识别，不改变当前文档卡片的选中描边，也不遮挡最近阅读的移除按钮。

## 兼容性与验证

- 中英文 UI 文案同步增加。
- Go 测试覆盖持久化、去重、记录独立性、失效文件以及草稿另存迁移。
- 前端测试覆盖侧栏模式归一化、路径状态映射和大小写不敏感收藏判断。
- 完成后同步版本为 v2.3.3，更新 README 与 CHANGELOG，并运行 Go、前端、静态检查和 Windows NSIS 生产构建。
