# GitHub 默认中文 README 设计

## 目标

让 GitHub 仓库首页默认展示简体中文项目介绍，同时保留完整英文文档和旧中文版链接的兼容性。

## 文件结构

- `README.md`：简体中文完整项目主页，GitHub 默认显示。
- `README.en.md`：English 完整项目主页。
- `README.zh-CN.md`：兼容入口，说明中文文档已经迁移到默认 `README.md`，并提供中文与英文链接。
- `AGENTS.md`：同步更新三个 README 文件的职责说明。

## 导航规则

- 中文主页顶部显示“简体中文”当前状态，并链接到 `README.en.md`。
- 英文主页顶部链接到 `README.md`，并显示“English”当前状态。
- 旧的 `README.zh-CN.md` 不删除，避免现有外部链接返回 404。
- 截图、下载链接、官网地址和锚点继续使用各语言现有内容。

## 内容保护

当前工作区中的字号同步、200% 缩放说明和其他未提交文档修改必须随对应语言页面一起迁移，不能被旧提交内容覆盖。

## 验证

- `README.md` 首屏必须是中文标题与中文介绍。
- `README.en.md` 首屏必须是英文标题与英文介绍。
- 三个 README 的语言链接指向存在的文件。
- 检查相对图片、许可证、贡献指南和源码构建链接没有失效。
- 执行 `git diff --check`，确认没有空白字符错误。
